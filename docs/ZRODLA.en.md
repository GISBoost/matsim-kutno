## 4. Literature and practice of MATSim (MUM 2026, `data/raw/mum2026/`)

- Medina Godoy (Valencia, UPV mobility, PT failure scenarios):
  - network from OSM, PT from GTFS via gtfs2matsim;
  - car / bike / pt / walk, bicycle as network mode (`mainMode=car,bicycle`);
  - `SubtourModeChoice` weight 0.1, attribute `carAvail`, 60 iterations, innovation switched off at 0.7;
  - sample 1–5%, calibration only of the modal split, not the densities.
  - For us: minimum configuration template for mode choice in G4.
- Lannes (Paris, pollution exposure):
  - on the regional scale sample size almost doesn't matter;
  - on the local scale, 5% gives a large error, and 25% has small randomness between runs.
  - This independently supports our decision regarding the results from 25% (D15).
- Bell (Newcastle, MATSim $\rightarrow$ Blender):
  - network nodes to scene coordinates (BlenderGIS);
  - events (`vehicle enters/leaves traffic`, `entered/left link`) $\rightarrow$ position of each vehicle for every frame $\rightarrow$ `vehicleMotions.npz`;
  - In Blender, one point mesh updated by the frame handler, vehicle shape via Geometry Nodes, render.
  - Example from the presentation: 142 thousand vehicles. Code was not found publicly. Locally there are Blender 4.3 and 4.4.
